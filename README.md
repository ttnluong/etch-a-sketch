# Etch-a-Sketch

A browser-based Etch-a-Sketch drawing tool built as part of The Odin Project Foundations curriculum. The project focuses on DOM manipulation, event handling, and dynamic UI generation using JavaScript.

## Live Demo

[View Demo](https://ttnluong.github.io/odin-etch-a-sketch/)

## Features
- Interactive grid-based drawing canvas
- Hover-based drawing functionality
- Adjustable grid size
- Clear/reset canvas option
- Dynamic grid generation using JavaScript

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

## What I Learned

Through this project, I practiced:

- DOM manipulation and dynamic element creation
- Handling mouse events for interactive drawing
- Using loops and functions to generate UI grids
- Managing state for user interactions
- Structuring JavaScript for modular behavior
